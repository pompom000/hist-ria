CALCULO 1 — APP DE ESTUDOS
Abra index.html no navegador do computador ou celular.
No celular, você pode usar "Adicionar à tela inicial" do navegador para deixar o app com acesso rápido.
O progresso é salvo localmente no navegador.
Conteúdos: conjuntos numéricos, intervalos, funções constante/identidade, afim, linear, quadrática, exponencial, logarítmica e limites intuitivos, além de exercícios.
